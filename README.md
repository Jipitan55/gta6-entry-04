SOLMAR HEAT: an original open-world crime game in the browser, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in total prizes.

Explore the sun-soaked city of Solmar Bay on foot and by car, steal cars, dodge traffic and fleeing pedestrians, raise your wanted level and outrun the Solmar Bay PD, and work three story missions for the fixer Vera Kline — steal the turquoise coupe, run a package across town, and survive a three-star heat wave. Pistol and fist combat, a live minimap, health and cash, busted/wasted states, and a save that carries your story between visits. No network needed: the whole game is static files under `game/`, with three.js vendored locally.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move / drive |
| Shift | Sprint |
| Mouse | Look (click to lock, drag to orbit) |
| Left click | Shoot pistol |
| Right click (hold) | Aim |
| F | Punch |
| E | Enter / exit car · pick up |
| R | Reload |
| M | Mute sound |
| P / Esc | Pause |

## Missions

1. **Hot Wheels** — steal the turquoise coupe on the east avenue and deliver it to Vera's garage ($800).
2. **The Package** — pick up a package at the pier on foot and deliver it to the Neon Bar ($1,200).
3. **Heat Wave** — the job goes loud at three stars; lose the cops, then reach the safehouse ($2,000).

Finish all three to become a Solmar Legend, then keep playing in free roam. Progress saves automatically when a mission completes (and from the pause menu) and continues from the title screen.
